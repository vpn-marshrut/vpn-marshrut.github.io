Исключения AdGuard VPN: сайты, приложения и противоположные режимы

Как настроить выборочный маршрут AdGuard VPN по платформе: сайты и приложения, взаимодействие списков, ограничения iOS/Integrated mode и проверка.

Сначала прочитайте активный режим исключений. В общем режиме запись выводит объект из туннеля; в выборочном — включает его в нужный охват. Затем измените один сайт или приложение и проверьте то же действие заново. Одинаковое название списка не означает одинаковое направление.

Ниже — отдельные процедуры по официальной KB, прочитанной 1 ноября 2026 года. Исключения клиента управляют уже доступным соединением и не являются способом создать мобильный сигнал или изменить операторский список разрешённых ресурсов.

Если пункта нет, сначала проверьте платформу и режим. Переустановка не добавит настройку, недоступную в этой схеме.

Android: вывести одну программу из туннеля

Эта ветка относится к обычному VPN mode, не к интеграции с блокировщиком.

  1. Откройте Exclusions — исключения.
  2. Выберите раздел приложений и прочитайте его режим. Для выхода выбранного приложения нужен общий режим «VPN везде, кроме списка».
  3. Сохраните исходное состояние, затем используйте Add app и выберите нужную программу.
  4. Заново откройте её соединение штатным способом и повторите нужное действие.

Ожидаемый результат: выбранная программа следует правилу обхода, остальные — своей политике. Проверка только IP другого браузера этого не доказывает. Для возврата удалите добавленную вами запись; не очищайте весь список пользователя.

В Integrated mode управление приложениями выполняется через блокировщик. Точная ветка включения интеграции есть в инструкции Android.

iOS: включить VPN только для выбранного сайта

Для обычного, не Integrated режима:

  1. Откройте Exclusions.
  2. Используйте Change mode и выберите работу VPN только для перечисленных сайтов.
  3. Добавьте домен нужного сайта через предусмотренный ввод. Для учебной проверки можно использовать example.org.
  4. Повторите запрос в том же браузере и сравните поведение другого сайта, который не включён в список.

Ожидаемый результат: выбранная область следует политике включения. У каждого режима свой список, поэтому переключение не означает автоматический перенос прежних записей.

Если сервис обращается к нескольким именам, одной главной страницы недостаточно. Проверьте авторизацию, API и медиа, а не добавляйте случайный большой список адресов. В Integrated mode iOS этот раздел недоступен — используйте другую документированную схему, если задача требует исключений.

Windows/Mac: проверьте браузер как приложение

Откройте Exclusions и проверьте одновременно правила сайтов и приложений. Если браузер исключён целиком, добавление его сайта в другой список может не дать ожидаемый маршрут. Сначала определите, должен ли браузер вообще входить в туннель.

Затем настройте один домен или одну программу, сохраните и повторите конкретное действие. Названия переключателей сверяйте с установленным выпуском; не копируйте Android-путь к кнопке на компьютер.

Linux: посмотреть, добавить и убрать одну запись

Сначала прочитайте текущее состояние:

adguardvpn-cli site-exclusions mode
adguardvpn-cli site-exclusions show

Если example.org ещё не присутствует и вы хотите проверить именно это изменение:

adguardvpn-cli site-exclusions add example.org
adguardvpn-cli site-exclusions show

В general запись означает обход; в selective — включение. Не меняйте режим только ради примера, не сохранив прежнюю политику. После проверки удалите лишь новую учебную запись:

adguardvpn-cli site-exclusions remove example.org

Результат: список изменён предсказуемо и возвращён обратно. Команды работают с перечнем соответствующего режима; перечни не следует считать одним общим набором.

Как завершить проверку

Запишите платформу, режим и одно ожидаемое направление. После изменения приложение может сохранять прежнее соединение, поэтому повторите сеанс предусмотренным способом. Обычный IP у исключённого объекта может быть ожидаемым результатом, а не признаком поломки.

Если вопрос связан с отсутствием сети, продолжайте в разделе белых списков, а если с ошибкой клиента — в диагностике VPN. Не подменяйте эти причины расширением списка исключений.

FAQ

Почему добавленный в исключения сайт пошёл через VPN, а не напрямую?

В выборочном режиме список задаёт объекты включения, тогда как в общем режиме — обхода туннеля. Сначала прочитайте активный режим и проверьте, какой перечень редактируется. Одинаковое слово «исключения» не задаёт одно направление.

Почему запись сайта не помогает, если браузер исключён как приложение?

Правила сайтов и приложений могут взаимодействовать. Исключённый целиком браузер может не использовать туннель для его страниц. Проверьте оба уровня политики, затем повторите действие в том же браузере, не импортируя сразу большой чужой список.

Можно ли на iPhone исключить отдельное приложение как на Android?

Не переносите Android-интерфейс на iOS. Официальный обзор iOS описывает исключения сайтов, а Integrated mode делает Exclusions недоступными. Проверяйте документированные возможности своей платформы вместо поиска одинакового списка программ во всех клиентах.

Почему одного домена недостаточно для сервиса с видео и входом?

Одна служба может использовать разные имена для авторизации, API и медиа. Запись знакомого домена не доказывает полный охват. Проверьте нужное действие и предусмотренный набор доменов, учитывая поддомены и альтернативные адреса.

Белый список клиента поможет при отсутствии мобильного интернета?

Он управляет маршрутом уже доступного соединения, а не создаёт сигнал или исходный канал. Операторский список разрешённых ресурсов — другой механизм. Сначала отличите отсутствие связи от ограниченного доступа и ошибки самого клиента.
